# Data and license notes

The source code in this repository is MIT licensed. The Open Bandit Dataset is
separate third-party material released under CC BY 4.0 by ZOZO/ZOZO NEXT. Cite
Yuta Saito, Shunsuke Aihara, Megumi Matsutani, and Yusuke Narita, “Large-scale
Open Dataset, Pipeline, and Benchmark for Bandit Algorithms” (2020), and link to
the ZOZO data release. User-related feature values are hashed by the source;
sampled row-level data are kept local, ignored by Git, and not redistributed.
